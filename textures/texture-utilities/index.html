TEXTURES

Texture utilities

loadImage, createPageTexture, drawImageWithFit and friends — re-exported from three-book.

See it live in the Staple playground or the Glued spine playground — every option on this page is a control there.

SOURCE
import {
  loadImage,
  createPageTexture,
  computeDefaultImageRect,
} from '@objectifthunes/react-three-book'

// 1 — decode a File picked from an <input type="file">
const loaded = await loadImage(file)        // → LoadedImage | null
if (!loaded) return

// 2 — build a CanvasTexture for a single page (page is 2×3 world units)
const texture = createPageTexture(
  '#fdfcf8',          // background colour
  '',                 // fallback label (drawn only when image is null)
  loaded.image,       // HTMLImageElement
  'cover',            // ImageFitMode: 'contain' | 'cover' | 'fill'
  true,               // fullBleed — no inner margin
  2,                  // pageW (world units) → canvas is pageW * PX_PER_UNIT
  3,                  // pageH (world units)
)

// 3 — optionally precompute the rect for a custom-positioned image
const rect = computeDefaultImageRect(loaded.image, 512, 768, 'cover', true)

// hand `texture` to a <Page texture={texture}> or your own BookContent…
// and when you no longer need it:
URL.revokeObjectURL(loaded.objectUrl)
texture.dispose()
FUNCTIONS
FunctionSignatureWhat it returns
loadImage(file) => Promise<LoadedImage | null>Decodes a File into an HTMLImageElement plus the object URL it came from. Resolves null when file is nullish or decoding fails. You own URL.revokeObjectURL(result.objectUrl).
createPageTexture(color, label, image, fitMode, fullBleed, pageW?, pageH?, imageRect?) => THREE.TextureWraps createPageCanvas in a sRGB THREE.CanvasTexture, ready to use as a page material. Call .dispose() when done.
createPageCanvas(color, label, image, fitMode, fullBleed, pageW?, pageH?, imageRect?) => HTMLCanvasElementSame drawing as above but returns the bare canvas — use when you only need a source (e.g. for TextOverlayContent) and want to skip the texture allocation.
drawImageWithFit(ctx, image, x, y, w, h, fit) => voidDraws image into a 2D context within (x, y, w, h) using contain / cover / fill.
computeDefaultImageRect(image, canvasW, canvasH, fitMode, fullBleed) => ImageRectReturns the {x, y, width, height} drawImageWithFit would use — handy to seed an ImageRect before the user nudges it.
TYPES & CONSTANTS
NameKindMeaning
PX_PER_UNITconst numberPixels per world unit (256). Canvas size = pageW/pageH × PX_PER_UNIT when those args are given; otherwise the canvas is 512 × 512.
ImageFitMode'contain' | 'cover' | 'fill'How the image is scaled into its area — letterboxed, cropped-to-fill, or stretched.
ImageRect{ x; y; width; height }Explicit image position and size in canvas pixels. Pass as imageRect to override fitMode placement.
LoadedImage{ image; objectUrl }The resolved value from loadImage — an HTMLImageElement and the object URL to revoke later.
NOTES

These helpers are re-exported verbatim from @objectifthunes/three-book — a single source of truth shared with the core library. They are browser-only (they touch document and URL), so call them in the client, not during server rendering.

Reach for them when you build content imperatively with useBookContent & useTextOverlay. If you prefer declaring pages as JSX, the Cover, Page & Spread components do this drawing for you.

Ownership is manual: a texture you create with createPageTexture must be dispose()d, and the objectUrl from loadImage must be revoked, or you leak GPU and blob memory.
