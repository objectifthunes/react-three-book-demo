DECLARATIVE CONTENT

Cover, Page & Spread

Declare covers, pages and double-page spreads as JSX children instead of building BookContent by hand.

See it live in the Staple playground or the Glued spine playground — every option on this page is a control there.

SOURCE
import { Book, Cover, Page, Spread, Text } from '@objectifthunes/react-three-book'

// frontImg / spreadImg are HTMLImageElement loaded via loadImage()
function MyBook({ frontImg, backImg, spreadImg }) {
  return (
    <Book binding={binding}>
      {/* Four covers, in surface order */}
      <Cover image={frontImg} fitMode="cover" fullBleed />
      <Cover color="#3a2a18" />            {/* front inner */}
      <Cover color="#3a2a18" />            {/* back inner  */}
      <Cover image={backImg} fitMode="cover" fullBleed />

      {/* Single page sides */}
      <Page color="#f5efe0">
        <Text x={70} y={120} fontSize={28} fontWeight="bold">Chapter One</Text>
      </Page>
      <Page color="#f5efe0" />

      {/* One image spanning two facing pages — adds TWO page entries */}
      <Spread image={spreadImg} fitMode="cover" fullBleed>
        <Text x={50} y={400} width={924} fontSize={18} textAlign="center">
          A panorama across the fold
        </Text>
      </Spread>

      <Page color="#f5efe0" />
    </Book>
  )
}
SHARED PROPS
NameTypeDefaultDescription
imageHTMLImageElement | null—Image to draw onto the surface. Load it with loadImage().
colorstring—Background fill (CSS color). Shows when no image, or behind a non-full-bleed image.
fitMode'contain' | 'cover' | 'fill'coverHow the image fits the surface (ImageFitMode).
fullBleedbooleanfalseExtend the image edge-to-edge with no margin.
imageRectImageRect | null—Custom image position/size in canvas pixels. Overrides fitMode when set.
children<Text> elements—Text blocks composited onto this surface.
SURFACES CONTRIBUTED
ComponentContributesNotes
<Cover>1 cover surfaceDeclare up to 4, in order: front-outer, front-inner, back-inner, back-outer.
<Page>1 page sideA single physical page side.
<Spread>2 page sidesOne image spanning two facing pages; text coordinates span the full double width.
NOTES

<Cover>, <Page> and <Spread> render nothing — they are data-only markers. <Book> reads their props during reconciliation and builds the underlying BookContent (cover surfaces and page sides). Change a prop and the content rebuilds automatically.

A book has four cover surfaces; declare them as four <Cover> elements in surface order. A <Spread> is a convenience for a single image across the fold: it adds two page entries (left + right), and any <Text> inside it is positioned against the full double-width canvas — so a centered title uses roughly twice the page width.

For styling text on any of these surfaces, see <Text>; for paper dimensions and the rest of the props, see <Book>.
